# 분석 방법론

## 1. 분석 단위

분석의 기본 단위는 **핵심품목(item)** 입니다. 산업마다 핵심품목이 정의되어 있고,
각 품목에는 국문·영문 검색 키워드가 붙습니다.

```
산업(industry) > 구분(section) > 중분류(large_category) > 핵심품목(item)
```

반도체는 24개 핵심품목이며, 품목별 키워드는 국문·영문 합산 1,382개입니다.

## 2. 가치사슬 3분류

"무엇을 만드는가"가 아니라 **"가치사슬 어디에 위치하는가"** 를 기준으로 분류합니다.
연구·투자의 쏠림과 공백을 진단하려면 품목 그 자체보다 위치가 중요하기 때문입니다.

| 구분 | 정의 |
|---|---|
| 본산업 | 분석 대상 산업 자체를 설계·생산하는 품목 |
| 전방산업 | 본산업 산출물을 채용하는 응용·수요 영역 |
| 후방산업 | 본산업에 투입되는 소재·부품·장비·기반 영역 |

본산업은 다시 **내부 가치사슬**로 교차 분류합니다.
반도체 기준: 제품기획·설계 → 설계검증 → 웨이퍼 제조 → 패키징·테스트 → 고객인증·양산

내부 가치사슬은 독립적인 품목이 아니라 **개발·생산·사업화 단계**이므로,
품목별로 수집한 자료를 대상으로 교차 분류하여 집계합니다.

## 3. 집계 기준 — 중복 처리

하나의 논문/과제가 여러 품목에 해당하는 경우가 많습니다.
예를 들어 특정 메모리 반도체의 테스트 장비를 개발하는 과제 하나가
해당 메모리 품목 · 패키징·테스트 · 검사·계측 장비 · 생산인프라 · 응용 수요산업까지
5개 분야에 동시에 걸치는 경우가 있습니다.

이때 분자와 분모를 **다르게** 처리합니다.

| 위치 | 처리 | 이유 |
|---|---|---|
| **분야별 값 (분자)** | 해당하는 모든 분야에 각각 계수 | 분야별 관련도를 보려면 모두 세야 함 |
| **합계·비율의 분모** | 과제번호+연도 기준 중복 제거 | 총 규모가 부풀려지면 안 됨 |

그 결과 **분야별 값을 모두 더한 합은 합계와 일치하지 않습니다.**
이는 오류가 아니므로 모든 해당 표에 주석으로 명시합니다.

> ※ 하나의 과제가 복수의 핵심 품목·연계분야에 해당하는 경우 각 분야에 중복 집계되므로,
> 분야별 값을 더한 합은 합계와 일치하지 않음(합계는 중복을 제거한 실제 규모)

실제 집계에서 중복 포함 값과 중복 제거 값의 차이는 논문·R&D 모두
**전체 규모의 10~20% 수준**으로 나타났습니다. 무시할 수 있는 크기가 아니므로
어느 분모를 쓰는지 표마다 명시해야 합니다.

## 4. 국가 기준

국가별 점유율의 분모는 **주요 5개국(한국·미국·중국·일본·대만) 논문 수 합계**로
통일합니다. 국제공동연구 논문은 참여국마다 계수되므로(국가 중복 계수),
국가별 점유율의 합이 반올림 때문에 100.0%와 다를 수 있습니다.

보고서 전체에서 이 기준을 벗어난 수치가 섞이지 않도록,
전체 국가 기준 값이 본문에 쓰였는지 검사하는 스크립트를 별도로 두었습니다.

## 5. 연도 기준

- 논문: 게재연도(Publication Year) 기준
- R&D 과제: 기준연도(=당해연도 연차). 다년도 과제는 연차마다 1건으로 계수하고
  정부투자연구비는 당해연도 금액을 사용
- 분석 기간: 최근 5년(2022~2026)
- 조사 시점상 2026년은 집계가 진행 중이므로, 절대 건수보다 비중·추이로 해석

## 6. 데이터 저장 구조

초기에는 검색조건(핵심품목 × 검색필드 × 연도)마다 파일을 따로 만들었으나,
분석할 때마다 폴더를 뒤져야 해서 비효율적이었습니다. 다음과 같이 변경했습니다.

```
output/{ntis|wos}/
  by_industry/{산업}.xlsx     ← 분석은 이 파일 기준
  raw/                        ← 검색조건별 원본 응답 (감사·디버그용)
```

검색조건 구분은 **폴더가 아니라 각 행의 태그 컬럼**으로 표현합니다.

| 컬럼 | 내용 |
|---|---|
| `source` | NTIS / WoS |
| `industry` | 산업 |
| `section` | 본산업 / 전방산업 / 후방산업 |
| `large_category` | 중분류 |
| `item` | 핵심품목 — 분석의 기본 단위 |
| `search_field` | TI(과제명) / KW(키워드) 등 매칭된 검색필드 |
| `year` | 기준연도 |

엑셀 필터나 피벗 하나로 원하는 산업·구분·연도 조합을 바로 뽑을 수 있고,
NTIS와 WoS는 보고서에서 따로 쓰이므로 계속 분리해 관리합니다.
