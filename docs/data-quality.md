# 데이터 품질 이슈와 대응

수집·집계·보고서 작성 과정에서 실제로 발견한 문제와 처리 방식입니다.

---

## 1. NTIS 검색어 공백 처리 — 수집 누락

### 증상

품목별 수집 결과가 비정상적으로 적었고, 24개 품목 중 다수가 0건이었습니다.
실제로 해당 분야에 R&D가 없어서인지, 질의가 잘못된 것인지 구분이 필요했습니다.

### 원인

NTIS OpenAPI의 검색어(`SRWR`) 문법은 다음과 같습니다.

| 연산 | 표기 |
|---|---|
| AND | **공백** |
| OR | `\|` |
| NOT | `!` |
| 완전일치(구문 검색) | `"..."` |

즉 **공백이 AND 연산자**입니다. 수집기는 키워드를 OR로 묶어
`"|".join(keywords)` 형태로 질의하는데, 여기에 띄어쓰기가 포함된 키워드가 섞이면

```
고대역폭 메모리|HBM|고대역폭 D램
```

이 `고대역폭 AND (메모리 OR HBM OR 고대역폭) AND (D램 …)` 처럼 해석되어
질의 전체가 깨집니다. 구문으로 검색하려면 `"고대역폭 메모리"` 처럼 감싸야 합니다.

### 규모

반도체 키워드 **1,382개 중 953개(69.0%)** 가 띄어쓰기를 포함하고 있었습니다.

| 구분 | 키워드 수 | 띄어쓰기 포함 | 비율 |
|---|---|---|---|
| 전체 | 1,382 | 953 | 69.0% |
| 국문 | 526 | 337 | 64.1% |
| 영문 | 763 | 604 | 79.2% |

영문 키워드(`high bandwidth memory`, `phase-change random-access memory` 등)의
비중이 특히 높았습니다.

### 대응

검색식 생성 단계에서 **공백이 포함된 키워드를 구문 검색으로 감싸도록** 수정하고
전체를 재수집했습니다.

### 배운 것

데이터는 받은 직후 **건수부터 확인**해야 합니다.
0건이 나온 조합은 "해당 데이터가 없다"가 아니라 "질의가 틀렸다"일 수 있습니다.

## 2. 국가명 표기 분산 — 집계 왜곡

### 증상

논문 저자 소속 주소 기준으로 국가별 집계를 했더니, 연구 규모가 큰 국가가
실제 순위보다 훨씬 낮게 잡혔습니다.

### 원인

원자료의 국가명 표기가 통일되어 있지 않아 같은 국가가 여러 표기로 흩어졌고,
그대로 집계하면 각 표기가 별개 국가로 계산되었습니다.

### 대응

표기 변형을 하나의 국가로 통일하는 정규화 규칙을 작성해 **집계 전에** 적용했습니다.
정규화 후 국가별 순위는 해당 분야의 알려진 연구 규모와 일치하게 복원되었고,
정규화 전에는 30위권으로 밀려 있던 국가가 2위로 돌아왔습니다.

### 배운 것

문자열 키로 집계할 때는 **집계 전에 정규화**가 필요합니다.
순위가 상식과 어긋나면 데이터가 아니라 전처리를 먼저 의심합니다.

## 3. 원자료 교체 시 버전 대조

원자료는 과제 진행 중 한 차례 이상 교체될 수 있습니다.
새 파일을 바로 반영하지 않고, **이전 버전과 품목 단위로 대조**한 뒤 반영했습니다.

- 품목별 건수·금액의 증감률을 모두 계산해 비정상적인 변화를 확인
- 변화의 원인이 데이터 자체인지, 집계 기준 변경인지 구분
  (예: 특정 품목의 논문 수가 크게 줄어든 것이 데이터 교체 때문이 아니라
  전체 국가 기준 → 주요 5개국 기준 변경의 결과인 경우)

## 4. 보고서 수치 자동 검증

최종 원고는 표 85개·그림 41개·113쪽 규모라 눈으로 확인할 수 없습니다.
원고(HWPX)를 직접 파싱해 **모든 수치를 원자료에서 재계산해 대조**하는
검증 스크립트를 두고, 원고를 고칠 때마다 반복 실행했습니다.

| 검증 항목 | 규모 |
|---|---|
| 논문 표 ↔ WoS 원자료 재계산 | 2,104칸 |
| R&D 표 ↔ NTIS 원자료 재계산 | 290칸 |
| 합계행 재검산 (성분 재합산) | 209칸 |
| 표 ↔ 표 교차 대조 | 359칸 |
| 본문 수치 ↔ 표·파생값(합·차·비율·증감률) | 1,523개 |
| 증감 방향·부호 모순 | 117건 |
| 배수·%p·증감률·순위 서술 | 101건 |
| 주요 5개국 기준 위반 탐지 | 본문 전수 |
| 표·그림 목차 번호·제목·쪽 | 126항목 |

### 이 과정에서 실제로 잡은 오류 유형

- **반올림 규칙 불일치** — `.5` 가 사사오입이 아니라 은행가 반올림으로 처리되어
  차트 라벨이 표와 1씩 어긋남 (예: 39,874.5 → 39,874 vs 39,875)
- **기준 혼입** — 보고서 전체가 주요 5개국 기준인데 일부 문장·그림만
  전체 국가 기준 값을 사용
- **분모 불일치** — 같은 문단에서 어떤 비율은 중복 제거 분모, 어떤 비율은
  중복 포함 분모를 사용
- **서술과 표의 불일치** — "N년 이후 1위 유지" 같은 서술이 실제 연도별 순위와 불일치
- **최상급 주장 오류** — "N개 품목 중 가장 높은"이 실제 최대값과 불일치
- **표·그림 배치** — 설명 문단과 해당 표 사이에 다른 그림이 끼어 들어간 경우

### 배운 것

분량이 커지면 **검증은 사람이 아니라 코드가 해야** 합니다.
"확인했다"는 느낌이 아니라 **몇 칸을 대조했고 몇 건이 불일치였는지**로 말할 수 있어야
같은 작업을 반복해도 품질이 유지됩니다.
