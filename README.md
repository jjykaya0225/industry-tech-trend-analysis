# 산업기술 환경예측 — 논문·정부 R&D 데이터 수집 및 분석 파이프라인

> 한국산업기술진흥원(KIAT) 「2027년 산업기술 환경예측」 과제의 기술동향 분석 파트에서
> 사용한 데이터 수집·집계 코드와 방법론입니다.

반도체·디스플레이·이차전지·로봇 4개 산업의 핵심품목별 **논문(Web of Science)** 과
**정부 R&D 과제(NTIS)** 를 수집하여, 가치사슬 관점에서 **연구·투자가 쏠린 영역과
비어 있는 영역을 진단**하는 것이 목적이었습니다.

본 저장소에는 **코드와 방법론만** 포함되어 있습니다. 원자료(WoS·NTIS)와 보고서 원고는
발주처 자료 및 데이터 제공자 라이선스에 해당하므로 포함하지 않았습니다.

## 2. 분석 설계

### 2-1. 가치사슬 3분류

핵심품목을 "무엇을 만드는가"가 아니라 **"가치사슬 어디에 있는가"** 로 재분류했습니다.

| 구분 | 정의 | 반도체 예시 |
|---|---|---|
| **본산업** | 반도체 자체를 설계·생산 | HBM, AI·연산 반도체, 웨이퍼 제조 … 12개 |
| **전방산업** | 반도체를 채용하는 응용 수요처 | AI 서버·데이터센터, 자동차·모빌리티 … 5개 |
| **후방산업** | 반도체 제조에 투입되는 소재·부품·장비 | 전공정 장비, 기초소재, 검사·계측 장비 … 7개 |

본산업은 다시 **내부 가치사슬 5단계**(제품기획·설계 → 설계검증 → 웨이퍼 제조 →
패키징·테스트 → 고객인증·양산)로 교차 분류했습니다.

### 2-2. 집계 기준

한 논문/과제가 여러 품목에 해당하는 경우를 다루는 방식을 명시적으로 분리했습니다.

- **분야별 값(분자)** — 해당하는 모든 품목에 각각 계수 (중복 포함)
- **합계·비율의 분모** — 중복을 제거한 실제 규모

그 결과 **분야별 값을 모두 더한 합은 합계와 일치하지 않습니다.** 이는 오류가 아니므로
해당 표마다 주석으로 명시했습니다. 국가별 점유율은
**주요 5개국(한국·미국·중국·일본·대만)** 합계를 분모로 통일했습니다.

### 데이터 저장 구조

검색조건마다 폴더를 나누면 분석 때마다 폴더를 뒤져야 해서,
**산업 단위 파일 1개 + 행별 메타데이터 태깅** 방식으로 바꿨습니다.

```
output/{ntis|wos}/by_industry/{산업}.xlsx
  → 각 행에 source / industry / section / large_category / item / search_field / year 태그
  → 엑셀 필터·피벗 하나로 원하는 조합을 바로 추출
raw/  검색조건별 원본 XML (감사·디버그용)
```

## 4. 데이터 품질 관리

상세 내용은 [`docs/data-quality.md`](docs/data-quality.md)에 있습니다. 요약하면:

**① NTIS 검색어 공백 처리 — 수집 누락**
NTIS OpenAPI는 검색어의 **공백을 AND 연산자**로 해석하고, 구문 검색은 `"..."` 로
감싸야 합니다. 띄어쓰기가 포함된 키워드를 그대로 OR 체인(`A|B|C`)에 넣으면
AND가 끼어들어 질의가 깨집니다.
반도체 키워드 **1,382개 중 953개(69%)** 가 여기 해당했고, 수정 후 전체를 재수집했습니다.

**② 국가명 표기 분산 — 집계 왜곡**
논문 저자 소속 주소의 국가명 표기가 분산되어 있어, 같은 국가가 여러 표기로 흩어진 채
집계되었습니다. 그 결과 연구 규모가 큰 국가가 실제 순위보다 훨씬 낮게 잡혔습니다.
표기 변형을 하나로 통일하는 정규화 규칙을 작성해 집계 전에 적용했습니다.

**③ 원자료 교체 시 버전 대조**
원자료가 교체될 때마다 이전 버전과 **품목 단위로 대조**한 뒤 반영했습니다.

**④ 보고서 수치 자동 검증**
최종 원고의 모든 표를 원자료에서 재계산해 대조하는 검증 스크립트를 두고 반복 실행했습니다.

| 검증 항목 | 규모 |
|---|---|
| 논문 표 ↔ 원자료 재계산 | 2,104칸 |
| R&D 표 ↔ 원자료 재계산 | 290칸 |
| 합계행 재검산 | 209칸 |
| 표 ↔ 표 교차 대조 | 359칸 |
| 본문 수치 ↔ 표·파생값 | 1,523개 |
| 표·그림 목차 번호·제목·쪽 | 126항목 |

## 5. 실행

```bash
pip install -r requirements.txt

# 1) 키워드 정의서 파싱
python src/keywords/parse_hwpx_keywords.py
python src/keywords/export_flat.py

# 2) NTIS 수집 (.env 에 NTIS_API_KEY 필요)
python src/collect/collect_ntis.py --industry 반도체

# 3) WoS 수집 (대학 도서관 구독 계정 필요)
python src/collect/wos_playwright.py --login-only
python src/collect/wos_playwright.py --industry 반도체
```

API 키는 `.env` 에만 두고 저장소에 올리지 않습니다 (`.env.example` 참고).
